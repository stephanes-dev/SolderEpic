# SolderEpic

Synchronizes distributed node processing with real-time data aggregation and automated server discovery.

With SolderEpic, you get a lightweight tool that stays out of your way.

## Installation

1. Clone the repository: `git clone https://github.com/yhonaach/SolderEpic.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

SolderEpic is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
